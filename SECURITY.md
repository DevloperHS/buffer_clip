# 🔒 Security policy

Thanks for helping keep Buffer Clip and its users safe.

## Please report security problems privately

If you find something that could put people at risk, **please don't post it in a public issue.** Public issues can be read by anyone, including people who might misuse the problem before it's fixed.

Examples of security problems:

- A way for a website to read recordings or data it shouldn't see.
- The extension recording something the user didn't choose to record.
- Typed passwords showing up in a recording.
- Anything that lets someone run code or take actions on another person's computer.

Not sure if it counts? Report it privately anyway. We'd much rather hear about it.

## How to report

1. Open the Buffer Clip repository on GitHub.
2. Click the **Security** tab near the top of the page.
3. Click **Report a vulnerability**.
4. Describe what you found and, if you can, the steps to make it happen. Screenshots or a short video help.
5. Click **Submit report**.

Only you and the project owner can see the report.

## What happens next

- We'll reply within **7 days** to confirm we've received your report.
- We'll keep you updated while we look into it and work on a fix.
- Once it's fixed, we'll publish a short note about it. If you like, we'll thank you by name.

## Which versions are supported

Buffer Clip is an early preview, so only the latest code on the `main` branch gets security fixes.

## How Buffer Clip handles your data

Buffer Clip runs entirely in your browser. Recordings and projects are stored on your own computer and are never uploaded anywhere by the app. The extension can only record the tab you choose, after you start it.
